# ZUPPIO Simple

This is the easier-to-edit Express + EJS version of the ZUPPIO website.

## Folder Guide

- `views/` - website pages. Edit these to change text and sections.
- `views/partials/` - shared header and footer.
- `public/images/` - product images.
- `public/stylesheets/style.css` - all design and responsive CSS.
- `public/javascripts/main.js` - simple animations and interactions.
- `routes/index.js` - page routes and flavor data.
- `app.js` - Express app setup.
- `bin/www` - server start file.

## Run

```bash
npm install
npm start
```

Open:

```txt
http://localhost:3000
```
